# 과육톤 운영 앱

2026년 11월 24일, GDG on Campus 서울과학기술대학교와 삼육대학교가 함께한 과육톤의 참가자·운영진용 웹 앱입니다. 이 저장소는 앱 소스와 합성 테스트를 담은 독립 아카이브입니다. 행사 운영 저장소와 그 Git 기록은 비공개로 보관합니다.

운영진은 엑셀 명단을 불러와 팀과 대표자를 배정하고 현장에서 출석을 기록합니다. 참가자는 Google 계정으로 들어와 시간표를 보고 QR 빙고에 참여합니다. 발표 때는 팀 대표자가 PDF를 제출하고, 체크인한 참가자들이 다른 팀의 발표에 한 표씩 남깁니다. 운영진 화면에서는 미제출 팀과 남은 시간을 한눈에 보고, 투표가 끝나면 가산점과 동점 재투표 결과를 반영해 수상 팀을 발표할 수 있습니다.

## 로컬에서 열기

Node.js 24와 pnpm 10.33.0으로 저장소 루트에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

[로컬 로그인 화면](http://localhost:3000/login)에서 행사 포스터와 설정 안내를 볼 수 있습니다. 약관과 개인정보 처리방침도 열립니다. 참가자·운영진 화면에 로그인하려면 본인의 테스트 프로젝트를 연결하고 명단에 계정을 등록하세요. [테스트 환경 설정](docs/setup.md)

## 코드 읽기

앱은 Next.js App Router와 TypeScript로 작성했고, Google 로그인과 DB·파일 저장소는 Supabase를 사용합니다. 투표를 예약한 뒤 누군가 늦게 체크인하면 어느 명단을 기준으로 할지, 팀이 제출한 PDF와 ZIP을 각각 누가 열 수 있는지는 DB 함수에서 결정합니다. [코드 구조와 운영 규칙](docs/architecture.md)

타입 검사, 단위 테스트와 빌드는 행사 계정 없이 실행할 수 있습니다. SQL 테스트에는 Linux 컨테이너를 실행할 수 있는 Docker가 필요합니다. [검증 방법과 문서 목록](docs/README.md)
