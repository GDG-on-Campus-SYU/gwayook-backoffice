# 과육톤 행사 이미지

2026년 과육톤 운영팀이 제공한 행사 포스터와 키캡 그래픽을 앱에 사용했습니다.

| 공개 파일 | 출처와 가공 |
| --- | --- |
| `public/brand/poster.webp` | 행사 웹 포스터를 가로 1400px WebP로 변환했습니다. |
| `public/brand/mark.png`, `app/icon.png`, `app/apple-icon.png` | 행사 키캡 그래픽의 귤 그림을 앱용 마크와 아이콘으로 내보냈습니다. |

저장소 관리자는 2026년 11월 17일 위 파일을 공개 코드 아카이브에 포함해 재배포할 권한을 확인했습니다. 이미지를 별도로 재사용·수정하거나 다른 라이선스로 배포하려면 권리자의 허가가 필요합니다. [MIT 라이선스](../../LICENSE)는 프로젝트 코드에 적용됩니다.
